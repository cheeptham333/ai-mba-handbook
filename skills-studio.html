ปรัชญา Co-Intelligence (Ethan Mollick) & การเปรียบเทียบ 3 ค่าย

ในหนังสือ Co-Intelligence: Living and Working with AI โดย Ethan Mollick ศาสตราจารย์แห่ง Wharton School ได้ชี้ให้เห็นว่า AI ไม่ใช่เพียงเครื่องมือค้นหา แต่คือ "เพื่อนร่วมงานและโค้ชคนใหม่" ที่มี 4 บทบาทหลัก

🎯
Socratic Coach

1. AI as Coach & Tutor

AI ไม่ได้ให้คำตอบทันที แต่ใช้เทคนิค Socratic Method ชวนผู้บริหารตั้งคำถาม ชี้จุดบอด และท้าทายสมมติฐานทางธุรกิจ เพื่อให้เราได้คิดค้นยุทธศาสตร์ที่เฉียบคมด้วยตนเอง

🤝
Centaur Mode

2. AI as Co-worker

ทำงานคู่กันแบบ Centaur (มนุษย์แบ่งงานชัดเจน ส่วนไหนคนทำ ส่วนไหน AI ทำ) ร่วมวิเคราะห์สภาพตลาด สังเคราะห์ข้อมูลงบการเงิน และร่างแผนกลยุทธ์แบบ Peer-to-Peer

💡
Lateral Thinking

3. AI as Innovator

กระตุกความคิดนอกกรอบเดิม ช่วยทำ Blue Ocean Strategy หา Value Innovation และท้าทายกรอบความเชื่อเดิมของอุตสาหกรรม (Challenging Industry Orthodoxy)

⚡
Cyborg Mode

4. AI as Extender

ทำงานผสานแบบ Cyborg (มนุษย์กับ AI กลืนเป็นเนื้อเดียวกันในกระบวนการทำงาน) ผลิตเอกสารรายงาน บันทึกบอร์ด หรือโมเดลตัวเลขด้วยความเร็วและความแม่นยำสูง

มิติการเปรียบเทียบ 🟣 Claude Skill (Anthropic) 🔵 Gemini Gem (Google AI) 🟢 Custom GPT (OpenAI)
ปรัชญาหลัก (Core Philosophy) Agentic Reasoning, Tool Use คุณภาพสูง, และการควบคุม Prompt อย่างมีระบบระเบียบผ่านไฟล์มาตรฐาน Multimodal First, ประมวลผลบริบทมหาศาล (1M-2M Tokens), ผสานกับ Google Workspace สมบูรณ์แบบ Conversational Ease, ขยายระบบผ่าน REST API (Actions), และระบบกระจายผ่าน GPT Store
มาตรฐานไฟล์และโครงสร้าง SKILL.md พร้อม YAML Frontmatter ตามมาตรฐาน agentskills.io System Instructions ใน Gem Manager + Google Drive Grounding Instructions + Conversation Starters + Knowledge Files + OpenAPI Spec
จุดเด่นที่สุดในงานธุรกิจ การวิเคราะห์ตรรกะกลยุทธ์ที่ลึกซึ้ง ภาษาไทยสละสลวย ร่างบอร์ดเมโมได้แม่นยำ การอ่านเอกสารยาว 500-1,000 หน้าพร้อมกัน ดึงข้อมูลงบการเงินจาก Google Sheets การเชื่อมต่อฐานข้อมูล ERP/CRM ภายนอก และการเขียนโค้ดวิเคราะห์ข้อมูล/สร้างชาร์ต
การพกพาและการนำไปใช้ซ้ำ สูงสุด (ไฟล์ .md สามารถส่งต่อและรันข้ามเครื่องมือ Agentic ได้ทันที) ใช้งานผ่าน Google Account และแชร์ผ่าน Workspace ภายในองค์กร แชร์ผ่านลิงก์สาธารณะหรือเฉพาะคนใน Workspace / Enterprise

🟣 วิธีติดตั้งบน Claude Projects & Claude Code (Agent Skills Standard) ▼

สำหรับ Claude Projects บนเว็บไซต์:

  1. เข้าสู่เว็บไซต์ claude.ai/projects และล็อกอินบัญชีของคุณ
  2. คลิกปุ่ม "Create Project" แล้วตั้งชื่อโปรเจกต์ เช่น "AI MBA Strategy Suite"
  3. ในส่วน "Project Instructions" ให้กดปุ่ม "📋 คัดลอก System Prompt" จากสตูดิโอนี้ในแท็บ Claude แล้วนำไปวาง
  4. อัปโหลดเอกสารธุรกิจที่เกี่ยวข้อง (PDF, Word, CSV) ในส่วน Project Knowledge เพื่อให้ Claude มีข้อมูลเฉพาะของบริษัทคุณ

สำหรับ Claude Code / Developer CLI:

  1. ดาวน์โหลดไฟล์ [skill-name].skill.md จากสตูดิโอนี้
  2. นำไฟล์ไปวางในโฟลเดอร์ .claude/skills/ ในไดเรกทอรีโปรเจกต์ของคุณ
  3. Claude Code จะค้นพบและเปิดใช้งาน Skill นี้โดยอัตโนมัติเมื่อเจองานที่ตรงกับ Triggers
🔵 วิธีสร้าง Gem บน Google Gemini ▼
  1. เข้าสู่ gemini.google.com/gems (ต้องใช้บัญชี Gemini Advanced / Workspace)
  2. คลิกปุ่ม "+ New Gem" ที่มุมขวาบน
  3. ตั้งชื่อ Gem และคำอธิบายย่อ
  4. ในช่อง "Instructions" ให้กดปุ่ม "คัดลอก System Prompt" จากสตูดิโอนี้ในแท็บ Gemini แล้วนำไปวาง
  5. คลิก "Save" เพื่อสร้าง Gem ของคุณ จากนั้นคุณสามารถเรียกใช้งาน Gem นี้ได้ตลอดเวลาผ่านแถบเมนูด้านซ้าย
🟢 วิธีสร้าง Custom GPT บน ChatGPT (My GPTs) ▼
  1. เข้าสู่ chatgpt.com/gpts/editor (ต้องใช้บัญชี ChatGPT Plus / Team)
  2. สลับไปที่แท็บ "Configure"
  3. ใส่ชื่อ Name และ Description ตามที่สตูดิโอนี้สร้างให้
  4. ในช่อง "Instructions" ให้คัดลอกคำสั่งในแท็บ Custom GPT จากสตูดิโอนี้ไปวาง
  5. นำข้อความ Conversation Starters ไปใส่ในช่องตัวอย่างคำถาม
  6. คลิกปุ่ม "Create / Update" ที่มุมขวาบน และเลือกการแชร์ (Only me / Anyone with a link)
✨ มาตรฐานสากล agentskills.io & Google Spark ▼

ตามมาตรฐานเปิดของ agentskills.io ไฟล์ SKILL.md ที่มี YAML Frontmatter ถือเป็นรูปแบบสากลที่สามารถนำไปใช้งานร่วมกับเครื่องมือ AI Agent ยุคใหม่ได้ทุกค่าย เช่น Google Spark, Antigravity, OpenDevin, Cursor, และ Claude Code โดยไม่ต้องแปลงรูปแบบซ้ำซ้อน
